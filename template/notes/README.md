# Research notes

This folder is an [Obsidian](https://obsidian.md) vault. Open it with *Open folder as vault*.

Suggested structure:

- `daily/`: lab-book style daily notes.
- `literature/`: one note per paper, linking to the PDF in `../literature/`.
- `ideas/`: hypotheses, questions, and analysis plans.

Personal workspace state (`workspace*.json`, caches) is git-ignored; shared settings in `.obsidian/` are tracked.
