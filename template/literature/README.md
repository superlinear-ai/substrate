# Literature

Store journal articles here, for example `author-year-keyword.pdf`.

- PDFs are git-ignored by default because they are usually copyrighted and large. Remove the `literature/**/*.pdf` rule in `.gitignore` if you want to track them.
- Keep your reading notes in `../notes/literature/`, one note per paper.
- Export your reference manager's library (for example `references.bib`) here so the bibliography is versioned.
